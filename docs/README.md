## 文档维护规则

1. 新需求先补充需求说明和指标字典，再修改任务模板、代码和验收脚本。
2. 场景任务文档必须说明输入资源、学生可编辑内容、服务端计算方式和合格条件。
3. 结果页面只显示服务端计算的运行数据；没有运行数据时不得显示通过。
4. 地图资源、机型参数和指标定义发生变化时，增加资源或任务版本，不改写已发布任务。
5. 现场记录放入 `artifacts/acceptance/`，文档仅说明命令、数据格式和判定方式。
