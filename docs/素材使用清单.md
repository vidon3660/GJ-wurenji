## 3 本轮验证依据

| 命令或结果 | 用途 | 结论边界 |
| --- | --- | --- |
| `npm run typecheck` | shared、simulation、server、web 类型检查 | 代码类型一致性；不替代运行时、数据库或浏览器验收 |
| `npm run build` | 四个工作区生产构建 | 构建产物可生成；不替代目标机房部署 |
| simulation Vitest：66 项通过 | 仿真包回归 | 纯函数和仿真规则测试；不代表三场景目标规模通过 |
| server Vitest：434 项通过、18 项跳过 | 服务端回归 | 跳过项仍需数据库或目标环境条件；不代表 PostgreSQL 端到端全部通过 |
| web Vitest：404 项通过 | 前端纯函数/组件回归 | 不代表浏览器 WebGL、地图资源、帧率和长时运行通过 |
| `npm run map:resources:acceptance`、`npm run vtl:resources:acceptance` | 地图资源 readiness 检查 | 只有实际资源和目标标签一致时才能作为正式资源记录 |
| `npm run class-concurrency:smoke`、`npm run target-environment:acceptance` | 目标环境并发与综合验收 | 需真实服务、账号、目标标签和签字记录；本地未执行不写成通过 |
