# 低空无人集群教学仿真软件完整操作手册

> 文档版本：V1.0  
> 编制日期：2026-08-14  
> 适用系统：当前 V3 教学工作台  
> 适用角色：教师、学生  
> 首批场景：城市无人机编队表演、城市低空物流  
> 截图环境：本地 Docker 部署 `http://localhost:3000/`

---

## 1. 手册说明

### 1.1 使用目的

本手册用于指导教师和学生按照完整教学流程使用低空无人集群教学仿真软件，重点解决以下问题：

1. 教师如何准备课程、班级、学生、任务模板和预设区域。
2. 教师如何创建训练或考核任务，选择规模模板，配置初始条件、订单和运行事件。
3. 教师如何将任务发布给整班或指定学生。
4. 学生如何理解任务条件并按阶段完成规划、验证、运行、异常处置和复盘。
5. 教师如何查看学生进度、过程证据、系统统计并完成人工评价。
6. 学生如何查看已发布成绩、分项意见和最终项目报告。

本手册按实际教学顺序编排，不按软件组件或开发模块编排。教师可以直接从第 4 章开始备课，学生可以从第 9 章开始操作。

### 1.2 业务定位

系统面向院校无人机集群应用教学，训练重点是项目理解、方案规划、多机运行组织、状态监控、异常处置和复盘评价，不是单机遥控器训练软件，也不是真机运行平台。

首批两个场景的教学差异如下。

| 对比项 | 城市无人机编队表演 | 城市低空物流 |
|---|---|---|
| 项目主线 | 区域规划、申报、飞前准备、运行报备、固定程序监控、异常处置 | 区域分析、航线规划、航线验证、订单调度、配送运行、动态重调度 |
| 核心空间对象 | 起降区、飞行区、表演区、缓冲区、观众区、应急降落区、电子围栏 | 中心机场、配送点、去程航线、返程航线、等待点、备降点、应急区域 |
| 核心文档 | 三份飞行申报 Word 文件 | 航线方案、验证结果、订单调度表、动态调度版本 |
| 核心运行对象 | 固定表演程序、编队分组、环境和设备状态 | 无人机、航线、订单、任务时刻和运行事件 |
| 核心评价点 | 场地规划、申报质量、飞前判断、风险识别、处置和报备 | 航线安全、往返可行性、调度效率、准时率、应急处置和重调度 |

### 1.3 重要边界

使用系统前必须理解以下边界：

- 系统中的飞行申报、T-60 申请、实际起飞动态和结束报备均为教学仿真，不连接空军、空管、公安、民航或其他政府系统。
- 表演场景使用固定规模和固定程序模板，不提供舞步图案设计、灯光编辑、轨迹制作或舞步软件内嵌编辑。
- 舞步软件生成的轨迹如需用于教学，应由软件供应方或平台资源管理员转化为经过校验的版本化表演模板包；教师和学生不能在普通任务页面直接导入后投入运行。
- 物流场景不模拟货物重量、货物类型、装卸、签收、仓储、机场地面作业或真实物流系统接口。
- 系统不会自动生成最优航线或最优调度，学生必须自主规划并处理系统提示的冲突和风险。
- 系统统计用于提供客观证据，最终成绩由教师确认。
- 飞行申报文件只自动检查是否创建、保存和提交，不自动判断专业内容正确性。

### 1.4 教学闭环

```mermaid
flowchart LR
    A["教师准备课程、班级和学生"] --> B["选择任务模板与预设区域"]
    B --> C["配置模式、规模、环境、订单和事件"]
    C --> D["预览并发布任务"]
    D --> E["学生接收任务并查看条件"]
    E --> F["学生按阶段完成规划与验证"]
    F --> G["学生执行仿真运行与异常处置"]
    G --> H["学生提交复盘总结"]
    H --> I["教师查看证据并人工评分"]
    I --> J["教师发布评价和单文件报告"]
    J --> K["学生查看结果并复训改进"]
```

## 2. 角色、账号与权限

### 2.1 教师权限

教师可以：

- 查看教学概览、任务生命周期和待评价项目。
- 管理实训任务模板、参考答案约束和评价体系。
- 查看预设区域及地图资源状态。
- 创建课程、班级，导入学生并向班级发布实训。
- 创建、复制、预览、发布、撤回、结束和归档 V3 任务。
- 查看学生阶段进度、规划成果、申报文件、运行时间轴和复盘报告。
- 在训练模式下发送提示或手动触发已配置事件。
- 按量表填写分项得分、分项意见和综合讲评。
- 发布评价结果和控制班级排行榜展示。

教师不能：

- 直接替学生绘制区域、航线或编排订单。
- 修改系统法规阈值、统一机型能力或底层事件影响逻辑。
- 将教师预设路线当作学生标准答案直接投入正式运行。
- 在考核任务开始后随意修改关键条件。

### 2.2 学生权限

学生可以：

- 查看分配给本人的训练和考核项目。
- 查看任务条件、阶段状态和允许操作。
- 完成区域、航线、申报文档、检查、报备、调度、运行和复盘。
- 在训练模式规定范围内修改、重提或从指定节点重训。
- 查看教师已发布的分数、意见、排行榜和项目报告。

学生不能：

- 修改教师发布快照中的模式、模板、区域、订单原始属性和事件条件。
- 查看其他学生的方案、文档、成绩或参考答案。
- 在物流运行中创建或使用未经验证的航线。
- 修改教师评分或系统权威运行证据。

### 2.3 演示账号登录

1. 打开系统地址。
2. 在登录页输入院校分配的邮箱和密码。
3. 演示环境可点击“教师演示”或“学生演示”。
4. 点击“登录平台”。
5. 进入平台后检查右上角显示的姓名和角色是否正确。

![登录页与演示账号](./完整操作手册截图/共通页面/02-登录页与演示账号.png)

演示环境教师账号为 `teacher@demo.local`。正式部署必须使用学校统一分配的教师和学生账号，不应在生产环境共享演示密码。

### 2.4 退出和切换账号

1. 点击右上角姓名。
2. 点击“退出登录”。
3. 回到登录页后重新选择账号。

当发布、评价或资源管理操作提示“仅教师可以管理 V3 任务”时，首先确认右上角是否为教师角色；若界面显示教师但接口仍拒绝，应退出后重新登录，使身份令牌和页面角色重新同步。

## 3. 首次登录和共通页面操作

### 3.1 首次登录引导

学生首次进入系统时会显示四步引导：

1. 找到当前实训。
2. 按阶段完成规划。
3. 运行并处置告警。
4. 开始首个操作。

可以点击“下一步”逐页查看，也可以点击“跳过”进入首页。之后可点击顶部问号图标“重新播放引导”。

![学生首次登录引导](./完整操作手册截图/共通页面/03-学生首次登录引导.png)

### 3.2 2D 与 3D 视图

项目页面右上方提供“2D”和“3D”切换。

- 2D 适合区域绘制、航点编辑、距离测量和时空关系判断。
- 3D 适合观察建筑高度、障碍物、航线高度、无人机和地形关系。
- 两种视图使用同一套 WGS84 业务坐标和项目数据。
- 切换视图不会改变学生成果，只改变观察角度。
- 在地图中选中区域、航线、无人机或事件后再切换视图，可以减少定位偏差。

如切换后视角不合适，先重新选中当前对象，再使用视图切换，不要通过连续大范围拖拽寻找对象。

### 3.3 环境图层

地图页面的“打开环境图层”用于控制专题数据，包括：

- 建筑与障碍物。
- 限制与风险区域。
- 定位导航覆盖。
- 通信链路覆盖。
- 环境与气象。
- 物流场景中的等待点、备降点和配送节点。

图层只用于观察和检查，不会因关闭显示而删除数据或绕过系统规则。

### 3.4 任务条件

学生进入项目后，应先点击顶部“任务条件”，核对以下内容：

- 项目背景、任务说明和完成要求。
- 训练模式或考核模式。
- 预设区域和规模模板。
- 计划运行时间。
- 初始气象、定位、通信和机队状态。
- 系统模拟事件。
- 物流订单数量、释放方式、需求分布和候选配送点。

![学生查看任务条件](./完整操作手册截图/共通页面/04-学生查看任务条件.png)

任务条件是发布时冻结的教学输入。学生发现条件与教师课堂说明不一致时，应在开始首个阶段前向教师确认，不要自行按其他任务条件操作。

### 3.5 项目活动与时间轴

顶部“项目活动记录”数字表示项目关键活动数量。记录范围包括：

- 阶段开始、提交、接受和退回。
- 区域、航线、文档和调度版本变化。
- 运行开始、暂停、重训和完成。
- 事件发生、告警、学生动作和系统结果。
- 教师讲评、评价保存和结果发布。

运行后的详细证据主要在“复盘评价”的统一时间轴查看，可按状态、事件、告警、处置和报备筛选。

### 3.6 告警中心说明

当前顶部“告警中心”保留为全局入口，但项目运行告警的完整操作面板位于“表演运行”“配送运行”和“应急处置”阶段。课堂中应以项目内告警栏为准，不能只依赖顶部图标。

## 4. 教师端课前准备

### 4.1 教学概览

教师登录后默认进入“教学概览”。

![教师教学概览](./完整操作手册截图/教师端/01-教学概览.png)

页面统计含义：

| 指标 | 含义 | 建议动作 |
|---|---|---|
| 待发布草稿 | 已保存但未发布的任务 | 打开草稿检查条件并生成预览 |
| 尚未开始 | 已分配但学生未进入首阶段 | 检查开放时间和学生账号 |
| 正在进行 | 学生处于某一项目阶段 | 查看最近进度和异常情况 |
| 已提交 | 学生已提交复盘或等待审核 | 进入学生项目完成评价 |
| 开放告警 | 当前仍需关注的运行告警 | 进入对应运行项目查看 |
| 待评价 | 已提交但未发布结果 | 完成量表评分和讲评 |

“最近学生进度”按最近活动排序，点击学生项目可只读查看完整阶段成果。

### 4.2 实训任务库和题库

点击左侧“实训任务库”。

![实训任务库与评价体系](./完整操作手册截图/教师端/02-实训任务库与评价体系.png)

当前系统中的“题库”不是纯理论选择题库，而是项目化实训模板库，通常包含：

- 场景类型和难度。
- 学生需要完成的任务清单。
- 参考答案约束，例如“任务全部完成”“不存在严重飞行安全问题”。
- 自动采集指标，例如冲突、禁飞区、返航余量、完成率、准时率、航程、利用率和响应时间。
- 教师评价维度和权重。

教师操作方式：

1. 点击左侧模板卡片。
2. 查看“学生任务”。
3. 核对“参考答案约束”。
4. 核对“评价体系”权重之和是否为 100%。
5. 点击“创建场景实训”，以当前模板进入任务创建流程。
6. 如需新模板，点击“新建模板”，按学校教研规则配置后保存。

参考答案约束不等于向学生展示标准方案。系统只用约束和仿真数据形成检查证据，教师仍需结合学生方案和过程判断。

### 4.3 预设区域库

点击左侧“预设区域”。

![预设区域与地图资源](./完整操作手册截图/教师端/03-预设区域与地图资源.png)

操作步骤：

1. 使用顶部场景筛选切换“城市编队表演”或“城市低空物流”。
2. 在左侧选择具体区域。
3. 通过 2D/3D 检查区域空间特征。
4. 打开或关闭专题图层，核对建筑、限制区、定位、通信和气象数据。
5. 查看高度基准、地形版本、DEM 服务、离线验收、业务坐标和资源校验摘要。
6. 确认区域满足课堂需求后点击“用此区域创建任务”。

区域选择原则：

- 表演基础课可选择空间开阔、边界清晰的区域。
- 表演进阶课可选择高楼、滨水、观众隔离或通信覆盖更复杂的区域。
- 物流基础课选择配送点少、遮挡少的区域。
- 物流综合课选择多配送点、多航线交叉和覆盖差异明显的区域。

### 4.4 DEM 与地图资源状态

区域页面出现以下状态时，不应宣称已接入正式权威 DEM：

- “环境回退”。
- “离线资源未就绪”。
- “区域包未配置版本化 DEM 地形资源”。
- “区域包未配置权威高程采样快照”。

当前界面可以显示教学起伏地形和 DEM 版本标识，说明技术链路已预留，但正式交付还需要授权 DEM 数据、版本化地形服务、采样快照、离线资源和目标环境验收。

正式 DEM 接入后的教师检查步骤：

1. 打开“预设区域”。
2. 选择目标区域。
3. 确认“DEM 服务”不是“环境回退”。
4. 确认“离线验收”为就绪状态。
5. 确认没有 DEM、影像和高程快照缺失提示。
6. 在 3D 中检查建筑、地形和航线高度关系。
7. 使用已知控制点复核高程基准和偏差。
8. 创建测试任务，验证 2D/3D、规则检查和运行回放使用同一高程数据。

### 4.5 班级与学生

点击左侧“班级与学生”。

![班级学生与实训发布入口](./完整操作手册截图/教师端/07-班级学生与实训发布入口.png)

#### 新建课程

1. 点击“新建课程”。
2. 填写课程名称、学期和必要说明。
3. 保存后再创建教学班。

#### 新建班级

1. 点击“新建班级”。
2. 选择所属课程。
3. 填写班级代码和班级名称。
4. 确认学期并保存。

#### 导入学生

1. 选中目标班级。
2. 点击“导入模板”下载标准表格。
3. 按模板填写学生姓名、邮箱等字段。
4. 点击“导入学生”并选择文件。
5. 导入完成后核对学生数量、邮箱和加入时间。
6. 对重复邮箱、空邮箱或错误班级数据先修正模板，再重新导入。

#### 从班级直接发布实训

1. 选中班级。
2. 点击“发布实训”。
3. 进入创建向导后，系统自动带入当前班级。
4. 完成任务配置并预览发布。

### 4.6 班级排行榜

在班级实训旁点击“排行榜设置”。

![班级排行榜设置](./完整操作手册截图/教师端/08-班级排行榜设置.png)

可配置项：

- 是否对学生可见。
- 展示人数。
- 姓名是否脱敏。

排行榜只显示教师已经发布的成绩。学生尚未完成、教师未评分或评价未发布时，不会进入榜单。系统没有独立竞赛模式，排行榜是普通教学任务的可选展示能力。

## 5. 教师创建和发布任务

### 5.1 打开五步向导

教师可从以下入口打开创建向导：

- 顶部“创建 V3 任务”。
- 教学概览中的“创建 V3 任务”。
- 实训任务库中的“创建场景实训”。
- 预设区域中的“用此区域创建任务”。
- 班级与学生中的“发布实训”。

向导固定为五步：

1. 场景与模式。
2. 模板与区域。
3. 变量与事件。
4. 发布范围。
5. 预览发布。

### 5.2 第一步：场景与模式

![任务向导场景与模式](./完整操作手册截图/教师端/09-任务向导-场景与模式.png)

操作步骤：

1. 填写“任务名称”。名称应包含课程、能力目标或场景，不建议只写“测试”。
2. 填写“项目背景”，描述教学情境和业务条件。
3. 填写“任务说明”，列明学生要完成的主要工作。
4. 填写“完成要求”，明确阶段成果、提交要求和截止条件。
5. 选择“城市编队表演”或“城市低空物流”。
6. 选择“训练模式”或“考核模式”。
7. 点击“下一步”。

训练模式适用于课堂练习和形成性评价：

- 开放完整检查结果。
- 可按发布策略退回和补交。
- 可设置多次规则检查和运行次数。
- 教师可发送提示或手动触发事件。
- 可从指定运行节点重新训练。

考核模式适用于阶段测试和课程考核：

- 过程反馈受限。
- 关键方案提交后锁定。
- 默认不允许学生暂停或回退。
- 不允许临时打开补交开关。
- 结果在教师发布前按策略隐藏。

### 5.3 第二步：模板与区域

![任务向导模板与区域](./完整操作手册截图/教师端/10-任务向导-模板与区域.png)

操作步骤：

1. 选择固定规模模板。
2. 阅读模板说明，确认配送点、订单、分组、并行方式和事件开放范围。
3. 选择与场景兼容的预设区域。
4. 核对区域的高度基准、DEM、坐标系和专题图层。
5. 物流场景勾选候选配送点，数量必须落在模板允许范围内。
6. 确认成果清单后点击“下一步”。

表演规模模板：100、500、1000、3000 架。

物流规模模板：3、5、10、20、50 架。

规模越大，开放的分组、并发、事件数量、影响范围、航线切换和批量重调度能力越多。教师不应为了追求画面规模而跳过前置能力训练。

### 5.4 第三步：变量与事件

![物流变量与事件](./完整操作手册截图/教师端/11-任务向导-物流变量与事件.png)

共通操作原则：

1. 先配置初始条件，再选择运行事件。
2. 初始条件表示项目开始前已经存在的状态。
3. 运行事件表示仿真时间推进后发生的变化。
4. 事件数量必须满足模板最小值和最大值。
5. 同时激活数量不能超过模板上限。
6. 考核任务应避免过多随机触发，保证不同学生条件可复现。
7. 发布后条件和随机种子冻结。

#### 通用事件字段

启用事件后，逐项设置：

- 触发方式。
- 初始告警等级。
- 发现延迟。
- 升级延迟。
- 持续时间。
- 影响范围和影响数量。
- 信息可见性。
- 是否允许升级。
- 处置时限。
- 恢复方式。
- 后续关联事件。

![事件通用字段](./完整操作手册截图/教师端/12-任务向导-事件通用字段.png)

字段解释：

| 字段 | 教学含义 |
|---|---|
| 触发方式 | 自动排程、指定仿真时间、阶段触发、时间范围、条件触发或前一事件后触发 |
| 告警等级 | 决定学生看到的初始严重程度和处置优先级 |
| 发现延迟 | 事件实际发生到学生可以发现之间的时间 |
| 升级延迟 | 事件未控制时升级所需时间 |
| 持续时间 | 事件在没有其他恢复条件时保持的时间 |
| 影响范围 | 单架、小批量、分组、航线、节点、局部区域或整体 |
| 信息可见性 | 直接告警、状态变化后告警或部分信息延迟显示 |
| 处置时限 | 用于评价学生响应时效，不等同于系统自动给出正确答案 |
| 恢复方式 | 学生处置、自动恢复、条件恢复或持续到任务结束 |
| 后续事件 | 用于构造事件升级、连锁影响和恢复后的次生变化 |

### 5.5 第四步：发布范围与时间

![任务向导发布范围](./完整操作手册截图/教师端/13-任务向导-发布范围与时间.png)

操作步骤：

1. 选择发布班级。
2. 设置开放时间和截止时间。
3. 选择“整班发布”或“指定学生”。
4. 指定学生时勾选目标学生。
5. 核对训练或考核反馈策略。
6. 点击“生成预览”。

注意事项：

- 每名学生会获得独立项目，不共享方案和成绩。
- 开放时间未到时学生不能正式开始。
- 截止时间用于教学管理，不应与仿真运行时段混淆。
- 考核模式下应在发布前确认结果展示范围和重试次数。
- 发布给错误班级时，如果无人开始可撤回；已有学生数据时应结束或归档并重新发布正确任务。

### 5.6 第五步：预览发布

预览页应核对：

- 项目名称、背景、任务说明和完成要求。
- 场景、模式、模板和区域。
- 表演架数或物流机群、配送点和订单数量。
- 初始环境和机队状态。
- 事件名称、细分类型、触发和影响摘要。
- 学生阶段序列。
- 发布班级、学生人数、开放和截止时间。
- 规则包、模板包、事件包、场景包和评价版本。

确认无误后点击“确认发布”。本手册截图采集过程中没有执行确认发布，不产生新的任务数据。

发布前检查失败时，不要反复点击发布，应根据错误回到对应步骤修改。身份错误应重新登录教师账号；资源错误应先检查区域和资源包；模板错误应核对候选配送点、机队总数、事件数量和必要字段。

## 6. 教师配置城市编队表演任务

### 6.1 教学目标

表演场景主要训练：

- 城市场地和环境分析。
- 九类功能区规划。
- 三份飞行申报材料编制。
- 飞前检查和起飞判断。
- T-60、实际起飞和结束报备流程。
- 固定表演程序状态监控。
- 气象、定位、电磁、通信和设备异常处置。
- 时间轴复盘和项目报告。

### 6.2 规模模板选择

| 模板 | 适合教学 | 事件和处置建议 |
|---|---|---|
| 100 架 | 基础流程、单架异常 | 1 个简单事件，单架或少量影响 |
| 500 架 | 小批量状态判断 | 简单升级、小批量处置 |
| 1000 架 | 分组运行 | 2 至 3 个事件，分组返航或降落 |
| 3000 架 | 多分组协同 | 并发事件、多分组处置和分区降落 |

### 6.3 初始条件

教师可配置：

- 风向、风力、阵风和降雨。
- 定位与电磁状态。
- 通信与控制状态。
- 设备状态和影响范围。
- 表演时间、机型、最大高度和观众条件等项目参数。

教师只选择状态，不修改具体安全阈值。超过限制的初始状态可能在飞前检查或起飞决策时形成阻断。

### 6.4 表演运行事件

运行事件只包含四类技术事件：

1. 气象事件。
2. 定位与电磁事件。
3. 通信与控制事件。
4. 无人机设备事件。

消防、医疗、人员受伤、观众拥挤、安保不足、公安指令和临时空域管制不进入表演运行事件库。这些内容只在申请函和安全应急预案中作为前期保障内容，由教师人工评价。

### 6.5 舞步软件与固定程序

当前学生端不提供舞步制作、图案编辑、灯光编辑和逐架轨迹编辑。平台管理员可以把外部舞步软件生成的本地 ENU 轨迹 CSV 导入为版本化表演程序，教师再把已激活程序冻结到表演任务中。

教学使用方式：

1. 管理员进入“资源包管理”，点击“导入舞步 CSV”。
2. 填写程序名称、语义版本和来源软件；也可先下载 100 架标准 CSV 模板。
3. CSV 必须包含 `aircraft_id,time_ms,east_m,north_m,up_m`，坐标单位为米，原点为学生规划的表演区中心。
4. 系统校验 UTF-8 编码、固定机群规模、完整时间轴、重复时刻、高度、水平半径和最大段速度，并保留原始 CSV 与 SHA-256。
5. 管理员激活通过校验的程序；同名旧版本按资源生命周期规则退役。
6. 教师创建城市编队表演任务时选择与固定规模一致的表演程序，发布快照冻结程序版本和摘要。
7. 学生进入运行阶段后，系统按导入的分组轨迹驱动 Cesium 运行态；若学生规划的表演区半径或高度范围不足，运行前会阻止启动并提示调整规划。
8. 未选择外部程序的任务继续使用平台内置固定程序。

首版支持 100、500、1000、3000 架，单个程序 10 秒至 30 分钟，最大高度 500 m、水平半径 5000 m、最大段速度 40 m/s。未经平台导入、校验和激活的外部轨迹文件不得直接作为课堂正式运行程序。

## 7. 教师配置城市低空物流任务

### 7.1 教学目标

物流场景主要训练：

- 城市建筑、禁限区域和覆盖环境分析。
- 固定中心机场与配送点关系判断。
- 去程、返程和备用航线规划。
- 航点、高度、等待点、备降点和应急区域设置。
- 航线硬性冲突、风险和效率提示处理。
- 订单、无人机、航线和时刻表编排。
- 配送运行监控、飞行处置、航线处置和动态重调度。
- 运行结果和应急处置复盘。

### 7.2 机群模板选择

| 模板 | 配送点和订单 | 运行方式 | 主要能力 |
|---|---|---|---|
| 3 架 | 1 点、3 至 6 单 | 单机在航、严格串行 | 单组往返航线和基础任务顺序 |
| 5 架 | 2 至 3 点、6 至 10 单 | 简单并行 | 多航线和基础订单分配 |
| 10 架 | 4 至 6 点、10 至 20 单 | 多机多航线 | 排序、时序和轻量动态变化 |
| 20 架 | 6 至 8 点、20 至 40 单 | 中等批量并行 | 动态插单、局部航线异常、批量调整 |
| 50 架 | 8 至 12 点、50 至 100 单 | 高并发、多批次 | 复合事件、航线切换和全局重排 |

### 7.3 订单生成条件

教师设置：

- 订单数量。
- 配送点分布。
- 普通、优先、加急订单比例。
- 时间窗口。
- 一次性、分批、动态或指定阶段释放。
- 确定性订单种子。

系统根据条件批量生成订单，教师不逐条填写。发布后订单编号和原始属性锁定，学生只能安排执行资源和时刻。

### 7.4 订单变化事件来源

向导中的“动态新增订单”“订单取消”“订单优先级变化”对应物流需求 `TEA-016 订单变化` 和 `ORD-005 动态释放`，用于训练运行中订单池变化和动态重调度。

这些事件不同于 `TEA-021 设备事件` 和 `TEA-022 航线事件`：

- 订单事件改变业务需求。
- 设备事件改变无人机能力或状态。
- 航线事件改变航段、航线、等待点或备降点可用性。
- 节点事件改变配送点、等待点或备降点状态。

### 7.5 设备事件

`TEA-021` 在页面上通过“无人机故障”进入，再选择细分类型：

- 电池消耗异常。
- 动力系统告警。
- 飞控系统告警。
- 传感器告警。
- 无法正常返航或降落。

影响范围可以是单架、小批量或分组，具体开放范围由机群模板限制。

### 7.6 航线和节点事件

`TEA-022` 在页面上通过“航线运行条件变化”进入，细分为：

- 航段运行条件恶化。
- 航线暂停运行。

等待点和备降点状态变化通过节点事件配置：

- 配送点状态变化。
- 等待点状态变化。
- 备降点状态变化。

运行中学生只能使用本人已经规划并验证的主方案或备用方案，不能临时绘制新航线绕过事件。

### 7.7 事件字段

`TEA-023` 对应页面的通用事件参数，包含触发阶段、时间、影响范围、严重程度、持续时间、恢复、升级和关联事件。当前系统已实现这些配置入口和运行摘要，事件具体业务内容由事件类型、细分类型和通用参数组合形成。

详细逐字段操作和截图见：[城市低空物流运行事件配置与处置操作手册](./城市低空物流运行事件配置与处置操作手册.md)。

## 8. 教师任务生命周期管理

### 8.1 状态含义

| 状态 | 含义 | 可用操作 |
|---|---|---|
| 草稿 | 尚未发布 | 继续编辑、复制任务、删除草稿 |
| 已发布 | 已创建学生项目但尚未正式运行 | 复制、检查资源更新、撤回、结束 |
| 进行中 | 已有学生开始 | 复制、结束 |
| 已结束 | 不再接受正常运行 | 复制、归档 |
| 已归档 | 历史只读 | 复制 |

### 8.2 复制任务

1. 在教学概览的 V3 任务列表找到任务。
2. 点击右侧“任务操作”。
3. 选择“复制任务”。
4. 系统创建新的草稿副本。
5. 修改名称、区域、模板、订单、事件和发布范围。

复制不会带入学生方案、操作日志、成绩和历史提交。

### 8.3 撤回任务

1. 对“已发布”任务选择“撤回任务”。
2. 填写撤回原因。
3. 确认撤回。

撤回适合尚未开始或发布条件有误的任务。已有学生开始时应谨慎操作并保留原因。

### 8.4 结束和归档

1. 对“已发布”或“进行中”任务选择“结束任务”。
2. 填写结束原因。
3. 学生不再继续正常项目流程。
4. 任务进入“已结束”后选择“归档任务”。
5. 归档后历史数据、文件、报告和成绩保持可追溯。

### 8.5 资源更新

已发布但未开始的任务可执行“检查资源更新”。教师需要比较当前冻结版本和新激活版本，再决定继续使用原版本还是另建任务使用新版本。已完成任务不应因资源升级重新计算成绩。

## 10. 学生端城市编队表演完整流程

表演项目共有 7 个阶段。

![表演项目阶段导航](./完整操作手册截图/学生端-表演/00-表演项目阶段导航.png)

### 10.1 阶段一：区域规划

#### 学习目标

根据城市空间、建筑、地面人群、风向、定位和通信环境，完成九类功能区规划。

#### 操作步骤

1. 点击“01 区域规划”。
2. 打开环境图层，观察建筑、限制区域、定位、通信和气象。
3. 在左侧功能区列表选择要绘制的区域类型。
4. 使用“矩形建面”或“多边形建面”。
5. 在地图上完成区域边界。
6. 选中区域后设置名称、朝向和容量等级等属性。
7. 使用“编辑顶点”调整边界。
8. 使用“整体移动”调整整个区域位置。
9. 使用距离与方位测量检查边界关系。
10. 添加必要的文字标注。
11. 依次完成起降区、飞行区、表演区、缓冲区、地面隔离区、观众区、操作区、应急降落区和电子围栏。
12. 查看“权威检查”。
13. 处理门禁阻断，理解提示和风险。
14. 保存版本并确认规划。

![区域规划与权威检查](./完整操作手册截图/学生端-表演/01-区域规划与权威检查.png)

#### 系统检查

- 九类区域是否完整。
- 必要区域的包含、相离、重叠和边界关系。
- 区域是否超出预设范围。
- 是否进入限制区或明显障碍物。
- 是否设置应急降落区和电子围栏。

系统检查提供几何证据，区域是否满足具体项目需要仍由教师评价。

#### 阶段成果

- 区域数据版本。
- 权威检查结果。
- 区域规划图。
- 操作和保存记录。

#### 常见问题

- 九类区域少一类：补齐后重新检查。
- 观众区与飞行区关系不合理：重新调整边界并测量距离。
- 应急降落区不可达：结合障碍物和隔离区重新选址。
- 地图对象难以选中：先在右侧列表选择区域，再在地图编辑。

### 10.2 阶段二：飞行申报

#### 学习目标

基于区域规划和任务条件完成三份教学申报材料。

#### 固定三件套

1. 《无人机临时飞行空域申请表》。
2. 《关于申请无人机临时飞行空域的函》。
3. 《安全应急预案》。

#### 操作步骤

1. 点击“02 飞行申报”。
2. 在左侧选择第一份文档。
3. 点击“在线查看”进入文档编辑器。
4. 根据右侧“任务信息参照”填写项目名称、时间、架数、机型、区域、坐标和最大高度。
5. 查看并引用学生已确认的区域规划图。
6. 保存文档，等待自动保存状态完成。
7. 返回文档列表并提交当前文件。
8. 对另外两份文件重复操作。
9. 确认左侧显示“3/3 已提交”。
10. 确认阶段状态为“申报材料已提交”。

![飞行申报三件套](./完整操作手册截图/学生端-表演/02-飞行申报三件套.png)

#### 文件版本

- 母版副本是系统为当前学生创建的初始版本。
- 每次保存和提交形成可追踪版本。
- 训练模式下教师退回后可重新编辑并提交。
- 审核与重提记录保留操作人、时间和关联版本。
- 可下载当前 Word 文件。

#### 内容检查边界

系统只检查文件是否创建和提交，不自动判断字段正确、三份文件一致、应急预案合理或行政合规。学生必须自行核对，教师负责人工评价。

### 10.3 阶段三：飞前准备

#### 学习目标

逐项检查无人机、地面站、定位、通信、气象、区域、人员和申报保障，并作出起飞决策。

#### 操作步骤

1. 点击“03 飞前准备”。
2. 按类别逐项查看检查内容。
3. 对每项选择正常、提示、告警或异常状态。
4. 填写必要记录和处置说明。
5. 对异常项完成处理或说明。
6. 确认所有检查项已确认。
7. 选择“允许起飞”“整改后起飞”“推迟起飞”或“取消表演”。
8. 填写判断依据。
9. 提交飞前准备结论。

![飞前检查与起飞决策](./完整操作手册截图/学生端-表演/03-飞前检查与起飞决策.png)

#### 起飞决策原则

- 允许起飞：全部关键门禁满足。
- 整改后起飞：存在可在起飞前完成的整改项。
- 推迟起飞：当前条件不满足，但预计可以恢复。
- 取消表演：风险无法在任务允许范围内消除。

判断依据应说明事实、风险、处置和结论，不能只填写“正常”或“同意”。

### 10.4 阶段四：起飞前报备

#### 学习目标

在仿真 T-60 节点确认任务和环境快照，形成起飞前一小时申请记录。

#### 操作步骤

1. 点击“04 起飞前报备”。
2. 核对项目名称、计划时间、机型、架数、最大高度、起降点和空域边界。
3. 核对联系人和联系电话。
4. 核对当前气象、设备、定位和通信状态。
5. 点击“提交起飞前一小时申请”。
6. 确认生成记录编号、提交人、提交时间和仿真时刻。

![起飞前一小时申请](./完整操作手册截图/学生端-表演/04-起飞前一小时申请.png)

本操作只形成教学记录，不会向真实管制系统发送数据。

### 10.5 阶段五：表演运行

#### 学习目标

监控固定表演程序、环境和编队状态，发现并处置技术异常。

#### 启动操作

1. 进入“05 表演运行”。
2. 核对 T-60 和飞前决策已完成。
3. 点击“确认开始起飞”。
4. 系统记录实际起飞动态并启动固定程序。

#### 监控内容

- 当前程序阶段和运行进度。
- 总架数、已起飞、空中、已降落、正常、告警、异常和失联数量。
- 各编队分组状态。
- 风向、风力、阵风和降雨。
- 定位、电磁、通信、设备和电子围栏。
- 告警时间、级别、影响范围和状态。

![表演运行监控与告警栏](./完整操作手册截图/学生端-表演/05-表演运行监控与告警栏.png)

#### 异常处置步骤

1. 发现数量或状态变化。
2. 选择告警并核对类别、级别和影响范围。
3. 确认告警。
4. 选择目标对象，例如单架、小批量、分组、多分组或整体。
5. 填写判断依据。
6. 选择暂停后续起飞、暂停表演、返航、降落、应急降落或中止等操作。
7. 提交处置。
8. 观察系统状态变化和事件是否控制、升级或结束。
9. 必要时执行后续操作。

训练模式可在任务允许时调整速度、暂停或从指定节点重训；考核模式通常不允许学生暂停和回退。

### 10.6 阶段六：结束报备

#### 学习目标

核对起飞、降落和异常数量，完成飞行结束报备。

#### 操作步骤

1. 点击“06 结束报备”。
2. 核对计划架数和实际起飞数量。
3. 核对正常降落和异常数量。
4. 选择“正常完成”“存在异常”或“运行中止”。
5. 填写正常降落数量和异常数量。
6. 存在异常时填写异常说明。
7. 对照系统权威清点结果。
8. 点击“提交飞行结束报备”。
9. 确认提交人、提交时间、数量一致性和权威判定。

![飞行结束报备](./完整操作手册截图/学生端-表演/06-飞行结束报备.png)

数量不一致时不要盲目提交，应回看运行状态和异常记录，确认是否存在未正常降落、失联或异常退出的无人机。

### 10.7 阶段七：复盘评价

#### 学习目标

使用系统统计和时间轴回放分析任务过程，提交飞后总结并查看教师结果。

#### 学生提交步骤

1. 点击“07 复盘评价”。
2. 查看流程完成度、风险识别率、处置时效、事件控制率、升级数量、告警确认率和清点一致性。
3. 使用时间轴筛选状态、事件、告警、处置和报备。
4. 定位事件发生、首次发现、首次操作、升级和结束节点。
5. 填写任务完成情况。
6. 填写主要问题。
7. 填写处置得失。
8. 填写改进措施。
9. 提交飞后总结。
10. 等待教师评价。

#### 结果查看

教师发布后，页面显示：

- 最终成绩。
- 区域规划、飞行申报、飞前准备、风险识别、处置流程和复盘质量分项成绩。
- 分项意见。
- 综合讲评。
- 最终项目报告文件。

![复盘评价与最终报告](./完整操作手册截图/学生端-表演/07-复盘评价与最终报告.png)

系统每个项目保留一个当前格式的最终报告文件，满足“评价结果只需要一个文件”的要求。

## 11. 学生端城市低空物流完整流程

物流项目共有 8 个阶段。

![物流项目阶段导航](./完整操作手册截图/学生端-物流/00-物流项目阶段导航.png)

### 11.1 阶段一：区域分析

#### 学习目标

识别固定中心机场、候选配送点、限制条件、覆盖环境、等待点和备降点。

#### 操作步骤

1. 点击“01 区域分析”。
2. 打开建筑、限制区、定位、通信、气象和运行节点图层。
3. 确认中心物流机场位置。
4. 查看教师冻结的候选配送点。
5. 在模板允许范围内选择正式启用配送点。
6. 查看候选等待点、备降点和应急区域。
7. 填写区域判断记录，说明障碍、覆盖和节点条件。
8. 确认正式配送点数量满足模板范围。
9. 提交区域分析。

![区域分析与配送点选择](./完整操作手册截图/学生端-物流/01-区域分析与配送点选择.png)

中心机场选址、停机位、装卸和地面运行不属于本阶段考核内容。

### 11.2 阶段二：航线规划

#### 学习目标

为每个启用配送点自主规划正式去程和返程航线，并在高阶模板中准备备用方案。

#### 新建航线

1. 点击“02 航线规划”。
2. 在配送点列表选择目标点。
3. 点击“新建去程航线”。
4. 设置名称、分组、保护范围、离场方向和进场方向。
5. 在地图添加、移动或删除航点。
6. 设置航点和航段高度、速度等允许参数。
7. 选择等待点、备降点和应急运行区域。
8. 保存去程航线。
9. 新建返程航线，或使用“复制为返程”后再调整。
10. 高阶模板可“复制为备用方案”。
11. 对所有启用配送点重复操作。

![航线规划与航点参数](./完整操作手册截图/学生端-物流/02-航线规划与航点参数.png)

#### 规划工具

- 撤销和重做。
- 添加航点。
- 复制为返程。
- 复制为备用方案。
- 批量高度。
- 空间关系。
- 距离与方位测量。
- 地图文字标注。
- 航线版本管理。

#### 规划原则

- 每个启用配送点至少一条正式去程和一条正式返程。
- 去返程不必完全重合，应考虑方向、冲突和覆盖。
- 航线不能穿越禁用区域和建筑障碍。
- 高度必须满足统一机型和区域规则。
- 等待点和备降点必须可达。
- 备用方案也必须独立验证。

### 11.3 阶段三：航线验证

#### 学习目标

通过规则检查和往返仿真证明正式航线可用，并识别风险。

#### 操作步骤

1. 点击“03 航线验证”。
2. 点击“检查与验证”。
3. 查看空间、机型能力、覆盖、运行节点、多航线关系和效率检查。
4. 点击问题项定位相关航线和航段。
5. 对硬性冲突返回航线规划修改。
6. 对运行风险决定修改或保留并说明。
7. 执行完整往返验证。
8. 查看机场起飞、去程、到达、返航和机场降落五个里程碑。
9. 核对航程、时间和剩余电量。
10. 确认所有正式往返组合完成验证。
11. 提交固定物流航线方案包。

![航线规则检查与往返验证](./完整操作手册截图/学生端-物流/03-航线规则检查与往返验证.png)

#### 结果等级

- 通过：满足硬性规则，无需阻断。
- 存在风险：允许继续，但需要在调度和复盘中说明。
- 存在硬性冲突：不得提交。
- 无法完成往返：必须修改航线或运行节点。

系统不会给出新的最优航点，只提供问题位置、类型和数据。

### 11.4 阶段四：订单调度

#### 学习目标

将系统订单分配到无人机和已验证航线，形成类似民航运行计划的飞行任务表和时刻表。

#### 订单池

订单池显示：

- 订单编号。
- 配送点。
- 优先级。
- 释放时间。
- 最早执行时间。
- 最晚到达时间。
- 当前状态。

#### 单条任务分配

1. 点击“04 订单调度”。
2. 在订单池选择订单。
3. 选择可用无人机。
4. 设置计划起飞时间。
5. 选择通往正确配送点的已验证去程航线。
6. 选择已验证返程航线。
7. 保存任务分配。
8. 查看预计到达、落地和再次可用时间。

#### 批量调度

高阶模板可：

1. 按配送点、优先级、状态、航线或无人机筛选。
2. 多选当前筛选结果。
3. 按配送点、优先级、去程航线或无人机分组。
4. 批量分配或调整起飞时刻。
5. 再逐条修正特殊订单。

![订单池与飞机任务分配](./完整操作手册截图/学生端-物流/04-订单池与飞机任务分配.png)

#### 无人机时刻表

时刻表以无人机为行，显示订单在以下七个节点的时间：

1. 等待执行。
2. 起飞。
3. 去程飞行。
4. 到达确认。
5. 返程飞行。
6. 降落。
7. 再次可用。

#### 调度检查

提交前处理：

- 未经验证或目的地错误的航线。
- 无人机重复占用。
- 电量不足。
- 同一无人机任务重叠。
- 不可接受的航线时空冲突。
- 未分配订单或缺少返航安排。

预计延迟和效率问题可按任务策略保留，但必须在复盘中说明。确认无硬性冲突后提交正式初始调度版本。

### 11.5 阶段五：运行准备

#### 学习目标

对正式航线、调度、无人机、订单、节点和环境进行最终 GO/NO-GO 复核。

#### 操作步骤

1. 点击“05 运行准备”。
2. 查看调度与任务检查。
3. 查看无人机可用和电量检查。
4. 查看正式航线和验证状态。
5. 查看订单完整性。
6. 查看机场和配送节点状态。
7. 查看气象、定位和通信环境。
8. 处理阻断项。
9. 对关注项填写判断依据。
10. 选择“允许执行”“调整后执行”“延迟执行”或“取消任务”。
11. 提交运行决策。

![运行准备与放飞决策](./完整操作手册截图/学生端-物流/05-运行准备与放飞决策.png)

存在阻断项时不能选择直接执行。调整后执行需要先完成相应修改并重新检查。

### 11.6 阶段六：配送运行

#### 学习目标

监控无人机、航线、订单、环境和任务时刻，保持配送运行安全有序。

#### 监控页面

页面主要区域：

- 顶部运行指挥条：状态、仿真时间、剩余时间、速度和活动告警。
- 左侧机队状态：无人机编号、状态、任务和电量。
- 中央地图：无人机、航线、节点和事件空间位置。
- 右侧订单态势和航线状态。
- 下方飞行任务与时刻表。
- 底部告警栏和事件时间线。

![配送运行监控与飞行任务表](./完整操作手册截图/学生端-物流/06-配送运行监控与飞行任务表.png)

#### 单架监控

选择无人机后核对：

- 当前位置和高度。
- 当前航线。
- 任务阶段。
- 当前电量。
- 定位和通信质量。
- 设备状态。
- 关联订单。
- 当前环境。

#### 任务监控

任务表显示订单、配送点、无人机、当前阶段、计划起飞、预计到达、预计落地和电量。发现延误、状态停滞或航线风险时，应进一步查看无人机和告警。

### 11.7 阶段七：应急处置

#### 学习目标

在设备、航线、节点、气象、定位、通信或订单变化下完成飞行处置、航线处置和动态重调度。

![应急处置运行工作台](./完整操作手册截图/学生端-物流/07-应急处置运行工作台.png)

#### 标准处置顺序

1. 发现状态变化或告警。
2. 确认告警并记录发现时间。
3. 选择受影响无人机、航线、节点或订单。
4. 判断当前任务处于等待、起飞、去程、到达、返程还是降落。
5. 填写判断依据。
6. 执行飞行处置。
7. 必要时暂停受影响航线或启用已验证备用方案。
8. 对未执行订单进行动态重调度。
9. 运行动态调度检查。
10. 处理硬性冲突后提交并生效。
11. 观察事件是否控制、恢复、升级或关联后续事件。
12. 完成应急处置阶段。

#### 飞行处置

可用动作根据对象状态和模板开放，包括：

- 继续监控。
- 减速。
- 悬停。
- 返航。
- 备降。
- 迫降。
- 中止任务。

动作提交前必须确认目标类型、目标对象和判断依据，避免对错误无人机或已完成任务执行操作。

#### 航线处置

- 暂停受影响航线。
- 恢复满足条件的航线。
- 切换到本人已验证的备用方案。
- 选择等待点或备降点。

运行中不得新建或启用未经验证的航线。

#### 动态重调度

1. 打开动态重调度面板。
2. 选择关联事件和调整模式。
3. 只调整尚未成为运行事实的订单。
4. 修改无人机、计划起飞、去程航线和返程航线。
5. 保存动态版本。
6. 查看硬冲突、风险、受影响订单和生效时刻。
7. 确认可提交后点击“提交并立即生效”。

已起飞、已完成或已形成权威运行事实的任务会锁定，不能通过重调度篡改历史。

### 11.8 阶段八：复盘评价

#### 学习目标

回放物流运行，分析航线、时效、冲突、利用率、异常响应和重调度结果。

#### 操作步骤

1. 点击“08 复盘评价”。
2. 查看系统统计参考。
3. 查看航线验证、按时完成率、运行冲突、无人机利用、异常响应和重调度分析。
4. 使用 2D/3D 回放。
5. 拖动统一回放时间轴定位关键节点。
6. 按状态、事件、告警、处置和报备筛选证据。
7. 填写原方案问题。
8. 填写处置得失。
9. 填写航线调整建议。
10. 填写调度优化。
11. 填写改进措施。
12. 提交运行复盘总结。

![物流复盘指标与总结提交](./完整操作手册截图/学生端-物流/08-物流复盘指标与总结提交.png)

提交后等待教师评价。教师发布结果后，学生可查看最终成绩、分项意见、综合讲评和单文件项目报告。

## 12. 物流事件配置与学生处置对应关系

### 12.1 事件分类与学生动作

| 教师配置事件 | 学生首先关注 | 典型动作 |
|---|---|---|
| 动态新增订单 | 新订单优先级、时间窗、可用机队 | 动态插单、调整任务顺序、重新分配无人机 |
| 订单取消 | 订单是否已形成运行事实 | 释放后续资源、移除未执行任务、重排队列 |
| 优先级变化 | 新优先级与最晚到达时间 | 调整起飞顺序和资源分配 |
| 配送点状态变化 | 受影响订单和到达节点 | 暂停任务、等待、转移后续订单 |
| 电池消耗异常 | 当前电量、航段、返航余量 | 返航、备降、任务转移 |
| 动力/飞控/传感器告警 | 无人机状态和任务阶段 | 悬停、返航、备降、迫降或中止 |
| 无法正常返航或降落 | 可用备降点和剩余电量 | 选择已验证备降方案并完成处置 |
| 航段条件恶化 | 航线和受影响航段 | 减速、等待、暂停航线、切备用方案 |
| 航线暂停 | 使用该航线的在航和待执行任务 | 保障在航安全，暂停后续任务，重调度 |
| 等待点/备降点变化 | 当前和计划使用该节点的任务 | 更换已验证节点方案或调整任务 |

### 12.2 事件生命周期

事件可能经历：

1. 未发生。
2. 已发生但学生尚未发现。
3. 已发现。
4. 正在处置。
5. 已控制。
6. 已升级。
7. 已结束。

学生评价不仅看最终是否恢复，还看发现、确认、判断、操作和结果之间的时间与证据是否完整。

### 12.3 事件内容是否完整

当前需求已经说明事件类别、细分类型、通用字段、影响范围和运行限制；系统也已提供对应配置和运行入口。仍需由课程设计进一步明确的是每套教学任务的具体情境，例如：

- 哪一架或哪一组无人机受影响。
- 哪个航段或节点变差。
- 状态变化的数值表现。
- 推荐处置时限。
- 哪些动作属于充分、过度或不足处置。
- 评价量表如何分配分值。

这些内容应形成版本化任务模板或事件资源包，不应由教师在课堂发布时随意修改底层规则。

1. 在进度表点击学生项目。
2. 系统进入“教师只读查看”。
3. 点击左侧阶段查看学生历史成果。
4. 点击“任务条件”核对发布输入。
5. 查看项目活动和复盘时间轴。
6. 不要在教师查看页替学生修改方案。

### 13.3 训练模式干预

在活动运行项目中，教师可按训练策略：

- 选择待触发事件并立即触发。
- 输入不超过限制字数的训练提示并发送。
- 观察学生是否发现、确认和处置。
- 在必要时结束训练。

### 13.4 讲评批注

复盘时间轴中的证据节点可添加讲评。批注应说明：

- 学生当时掌握的信息。
- 正确识别的风险。
- 判断或操作中的问题。
- 更合理的下一步动作。

避免只写“错误”“不规范”而不给出证据位置和改进方向。

## 14. 教师评价、发布结果和报告

### 14.1 打开待评价项目

入口：

- 教学概览“待评价”。
- 学生进度筛选“待评价”。
- 最近学生进度中的已提交项目。

### 14.2 系统统计参考

系统统计不自动决定最终成绩。物流复盘示例包含航线验证、订单完成率、准时率、告警发现率、处置时效、事件控制率和动态重调度。

![物流复盘统计与回放](./完整操作手册截图/教师端/05-物流复盘统计与回放.png)

教师应同时查看：

- 任务条件和模板难度。
- 学生规划和版本变化。
- 验证风险是否被正确理解。
- 运行中实际信息和动作时机。
- 复盘内容是否与证据一致。

### 14.3 分项评分

教师综合评价区按冻结的评价版本显示评分项和满分。

![教师复盘评分与发布评价](./完整操作手册截图/教师端/06-教师复盘评分与发布评价.png)

操作步骤：

1. 逐项输入得分，不得超过满分。
2. 填写分项意见。
3. 填写综合讲评。
4. 确认全部评分项已完成。
5. 点击“保存评价”。
6. 复查总分和意见。
7. 点击“发布评价”。

物流常用评价维度：

- 区域与航线规划。
- 航线验证与风险识别。
- 订单与机群调度。
- 运行监控与时序管理。
- 应急处置与动态重调度。
- 复盘质量与改进建议。

表演常用评价维度：

- 区域规划。
- 飞行申报。
- 飞前准备与动态报备。
- 风险识别与决策。
- 处置流程与结果。
- 飞后复盘质量。

### 14.4 保存和发布区别

- 保存评价：教师可以继续修改，学生不一定能看到最终结果。
- 发布评价：冻结当前结果并向学生开放允许展示的内容。

发布前应检查姓名、任务、量表版本、分项总和、综合讲评和报告文件。

### 14.5 最终报告

项目报告汇总：

- 项目基本信息。
- 学生规划或航线成果。
- 文档、检查、报备或调度状态。
- 运行证据和事件时间轴。
- 系统统计。
- 教师评分和讲评。

每个项目保留一个当前格式文件。表演报告需要标注教学仿真声明，不得作为实际行政申报或飞行管制材料。

## 15. 训练模式和考核模式操作差异

| 操作项 | 训练模式 | 考核模式 |
|---|---|---|
| 规则问题显示 | 显示位置、类型和相关数据 | 通常只显示冲突、风险和可提交状态 |
| 方案修改 | 允许多次修改、验证和对比 | 提交前可修改，提交后锁定 |
| 补交 | 教师可在发布时允许 | 默认关闭 |
| 运行暂停 | 可按策略暂停、加速或重训 | 通常固定速度，不允许学生暂停 |
| 教师提示 | 可发送方向性提示 | 默认禁止过程提示 |
| 教师触发事件 | 可触发已配置事件 | 按预设自动触发 |
| 结果反馈 | 可显示完整复盘 | 按教师设置显示总分、分项或完整复盘 |
| 过程记录 | 保存版本和操作 | 额外关注修改次数、验证次数和完成时间 |

教师创建考核任务前应先用同一模板发布训练任务，让学生熟悉页面和提交规则，避免把软件操作熟悉度误当作专业能力。

## 16. 常见问题与处理

### 16.1 无法点击“下一步”或“生成预览”

检查：

- 必填文本是否填写。
- 场景和模式是否选择。
- 模板和区域是否兼容。
- 候选配送点数量是否满足范围。
- 机队初始状态数量之和是否等于模板规模。
- 事件数量是否满足模板要求。
- 事件必要字段是否完整。
- 是否选择班级和目标学生。
- 开放时间是否早于截止时间。

### 16.2 发布提示仅教师可管理

1. 检查右上角角色。
2. 退出登录。
3. 重新使用教师账号登录。
4. 重新打开草稿。
5. 问题仍存在时检查服务端身份配置和会话有效期。

### 16.3 地图或 3D 视图没有定位到对象

1. 切回 2D。
2. 在区域、航线、无人机或事件列表中重新选中对象。
3. 再切换 3D。
4. 检查对象坐标是否在当前预设区域。
5. 检查 WGS84 数据是否错误地使用了 GCJ-02。

### 16.4 地形显示但 DEM 状态未就绪

当前可能使用教学起伏地形或环境回退。正式验收必须以区域资源页面的 DEM 服务、离线验收和高程快照状态为准，不能仅凭 3D 画面有起伏判断已接入权威 DEM。

### 16.5 文档无法编辑或保存

检查：

- 当前是否为可编辑阶段。
- 文档是否已提交并锁定。
- 是否为考核模式已提交版本。
- 在线文档服务是否健康。
- 浏览器是否阻止了编辑器加载。

训练模式被退回后，应从审核记录进入新版本，不要修改已提交历史版本。

### 16.6 航线不能提交

检查：

- 每个正式配送点是否都有去程和返程。
- 是否存在禁限区、建筑、高度或航程硬性冲突。
- 等待点和备降点是否可达。
- 所有正式航线是否完成往返验证。
- 备用方案是否错误地被标记为正式但未验证。

### 16.7 调度不能提交

检查：

- 是否存在未分配订单。
- 无人机是否重复占用。
- 是否使用错误配送点航线。
- 是否使用未经验证的航线。
- 起飞时间是否造成同机任务重叠。
- 电量是否满足往返。
- 硬性时空冲突是否处理。

### 16.8 运行中没有可用处置动作

可能原因：

- 当前没有活动事件或告警。
- 尚未确认告警。
- 没有选择受影响目标。
- 事件状态与动作不匹配。
- 当前阶段是历史只读状态。
- 模板规模未开放该层级操作。

### 16.9 动态重调度项目被锁定

已形成运行事实的任务不能修改。只调整未起飞或尚未执行的订单；对在航无人机先执行飞行处置，再安排后续订单。

### 16.10 学生看不到成绩

检查：

- 学生是否已提交复盘。
- 教师是否完成全部分项评分。
- 是否点击“保存评价”后又点击“发布评价”。
- 考核结果展示策略是否只显示总分或暂不显示。
- 当前登录是否为正确学生账号。

### 16.11 排行榜没有数据

排行榜只统计已发布成绩。检查排行榜是否启用、展示人数、姓名显示策略，以及目标实训是否已有已发布评价。
